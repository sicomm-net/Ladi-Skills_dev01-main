## Description
This starter app uses the formR folder structure.  It is opinionated with
a clear seperation of client versus server code.
- Start with a single `c11_index.html` in a client folder, `client1/c11_my-first-client-app`.
- Start with a single `s11_server.mjs` express app, in a server folder, `server1/s11_my-first-server-api`.
